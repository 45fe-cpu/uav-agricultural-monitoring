# UAM-7: Preliminary System Architecture

These editable Mermaid diagrams describe the *proposed* architecture of the diploma project, **Development of an Intelligent Software System for Agricultural Monitoring Using Multispectral UAV Imagery**.

- `system-context.mmd`: system boundary, users, and imagery input
- `use-case.mmd`: proposed user-facing functions
- `component-diagram.mmd`: frontend, backend, processing, inference, and storage components

Scope assumptions: one crop will be chosen after dataset validation; user authentication and a self-trained ML model are required, while exact frameworks, trained model, and anomaly labels are not yet finalized. Diagrams are plans, not evidence of implemented features.

To export visual diagrams, open https://mermaid.live/, paste each `.mmd` file's contents, and use Actions > Export (SVG/PNG).
